# 🌟 Project Overview
This portal serves as a gateway for aspiring designers to explore design principles, professional software, and creative workflows. Whether for business branding, school projects, or personal artistic expression, the studio provides the tools and information needed to start creating.

# 🚀 Key Technical Features
- **Curriculum Gateway**: Direct links to specialized lesson plans, skill-building modules, and professional service rates.
- **Interactive Audio Engine**: A custom **JavaScript-powered** system that allows users to upload and play their own background music locally while they work.
- **Resource Integration**: Fast-access "Pill" button logic linking directly to Pixabay for a massive library of royalty-free inspiration.
- **Clean UI Architecture**: A centered, "Studio-First" layout designed to minimize distractions and focus entirely on the creative process.

# 🛠️ Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **File API Logic**: Handles local music uploads and state management for the audio player.
- **Dynamic Object URLs**: Uses `URL.createObjectURL` to generate paths for audio files without requiring a backend server.
- **Styling**: Custom "Pill" button components and responsive layout centering.

# 📖 How to Use
1. **Explore Lessons**: Click the header to view the full Graphic Arts curriculum and pricing.
2. **Find Assets**: Use the Pixabay button to source high-quality backgrounds for your projects.
3. **Set the Mood**: Use the "Upload Your Own Music" tool to play your favorite creative playlist directly in the browser while you design.

# 📁 File Structure
- `index.html`: The main creative landing page.
- `graphics.html`: Detailed lesson plans, modules, and rates.
- `audioInput`: Custom JavaScript logic for the local MP3 player integration.
